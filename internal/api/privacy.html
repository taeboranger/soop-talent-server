SoopTalent

개인정보처리방침

최종 수정일: 2026년 8월 29일

SoopTalent은 스트리머가 SOOP 시청자의 방송 참여를 달란트로 관리할 수 있도록 돕는 서비스입니다. 광고·행태 분석·개인정보 판매를 하지 않습니다.

1. 수집·이용하는 정보

정보이용 목적
SOOP OAuth로 검증한 SOOP 아이디·닉네임로그인, 계정 식별, 관리자 권한 확인
암호화된 SOOP OAuth 토큰방송국 본인 확인, 공식 채팅 수집 및 토큰 자동 갱신
공개 채팅의 참여자 아이디·닉네임·메시지·시간, 공개 랭킹 정보스트리머별 달란트 적립과 적립 내역 표시
게시글·댓글 식별값 및 구매 신청 댓글수동 달란트 지급, 달란트 시장 보상 신청 처리
스트리머가 등록한 보상 이미지·설정값달란트 시장과 지급 기준 표시

2. 수집 방법과 범위

정보는 사용자가 SOOP OAuth 로그인·설정 저장·시장 등록을 할 때, 또는 스트리머가 연결한 공개 SOOP 방송 및 방송국에서 기능 수행에 필요한 범위로 수집됩니다. 로그인 계정에는 이메일이나 브라우저 정보 대신 SOOP 아이디와 최신 닉네임만 저장합니다. SOOP 비밀번호, 다른 채널의 시청 기록, 개인 메시지는 수집하지 않습니다.

3. 확장 프로그램의 처리

스트리머 확장은 로그인 세션 토큰과 동기화 상태를 브라우저 저장소에 보관하고, 일별 공개 랭킹·수동 달란트 지급 요청을 서비스로 전송합니다. 시청자 확장은 로그인하지 않으며, 열린 시장 글인지 확인하기 위한 방송국·게시글 번호와 잔액 조회에 필요한 SOOP 아이디만 서비스로 전송합니다. 두 확장 모두 광고, 추적기, 판매 목적의 분석 기능을 포함하지 않습니다.

4. 보관 기간과 삭제

계정, 달란트 적립 내역, 시장 주문 정보는 서비스 제공과 부정 적립 방지를 위해 서비스 이용 기간 동안 보관합니다. 삭제를 원하면 아래 문의처로 요청할 수 있으며, 법령상 보관 의무가 없는 정보는 처리 목적이 끝난 뒤 삭제하거나 익명화합니다.

5. 제3자 제공과 처리 위탁

개인정보를 판매하거나 광고·분석 사업자에게 제공하지 않습니다. SOOP OAuth 로그인과 공식 Chat SDK 연결 과정에서 SOOP이 각자의 정책에 따라 인증 정보를 처리합니다. SOOP에 대한 요청은 사용자가 사용하는 확장 프로그램 또는 서비스 기능을 통해 승인된 기능 범위에서 이루어집니다.

6. 이용자의 권리

이용자는 자신의 정보에 대한 열람·정정·삭제·처리 정지를 요청할 수 있습니다. 타인의 방송 참여 정보는 해당 스트리머의 운영 범위와 관계 법령을 고려해 처리합니다.
